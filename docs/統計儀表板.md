# 統計儀表板（stats）

管理端的超級專屬權限模組 `stats`（`scope: superOnly`）與其頁面 `/admin/stats`：
彙整目前專案在 **Vercel** 與 **Firebase（Firestore）** 的使用量，對照免費額度並顯示近期趨勢，
供超級管理員判讀「額度快用完了沒」（Firestore 讀取曾單日衝至 4.2 萬次逼近 5 萬免費額度）。

- **入口**：管理員首頁 →「統計儀表板」卡片 → `/admin/stats`
  （版頭、權限閘門與頁尾由共用 `admin/stats/layout.tsx` 提供，
  閘門為 `adminModules.includes("stats")`，fail-closed：讀不到權限＝權限不足）。
- **只讀、不落庫**：用量資料不寫入 Firestore（避免加重讀取量），
  由伺服器端 5 分鐘記憶體快取後回給前端；未設定環境變數時回「設定指引」而非錯誤。
- **金鑰不外流**：`VERCEL_TOKEN` 與服務帳號只在伺服器端使用，CSP 不需因本頁調整。

## 名詞

| 名詞 | 說明 |
|---|---|
| 免費額度 | Vercel 方案（Hobby／Pro）的每月內含量；Firestore 的每日內含量（太平洋時間午夜重置） |
| 計費週期 | Vercel 用量以「本月 1 日 ~ 次月 1 日（UTC）」區間查詢 |
| 太平洋日曆日 | Firestore 額度重置時區（`America/Los_Angeles`）的日曆日，程式以 `startOfPacificDay()` 切日 |
| FOCUS | Vercel `/v1/billing/charges` 回傳的計費開放標準格式（JSONL，逐行一筆 charge） |

## 資料模型

**不寫 Firestore**，僅 API 回應型別（`src/types/usage.ts`，不含 `server-only`，前後端共用）：

```ts
interface QuotaMetric { key: string; label: string; used: number; limit: number | null; unit: QuotaUnit; rawUnit?: string }
type QuotaUnit = "bytes" | "count" | "hours" | "gbHours" | "raw";   // raw＝單位無法辨識，附原始單位字串
interface UsageSection { ok: boolean; configured: boolean; message: string | null; hint: string | null; fetchedAt: string }
interface VercelUsage extends UsageSection { plan: string; period: { from: string; to: string }; metrics: QuotaMetric[] }
interface FirebaseUsage extends UsageSection { today: {reads;writes;deletes}; limits: {...}; daily: FirestoreDayUsage[] }
interface StatsResponse { success: boolean; vercel: VercelUsage; firebase: FirebaseUsage }
```

- `configured=false`：環境變數未設定（顯示設定指引卡）；`configured=true` 且 `ok=false`：已設定但抓取失敗。
- `limit=null`：該方案無免費額度或單位無法換算，前端顯示「額度未知」。
- `daily` 由舊到新含今日，日期字串為太平洋日曆日。

## API

`src/app/api/admin/stats/route.ts`

| 方法 | 行為 |
|---|---|
| `GET` | 回 `StatsResponse`；兩個來源以 `Promise.all` 各自抓取、互不阻斷，`Cache-Control: no-store` |

- 守門：`requireAdminModule("stats")` —— `adminModulesOf` 對非超級一律剝除該模組，
  因此等同「僅超級管理員」，與頁面層判斷同一把尺。
- 限流：`RATE.ADMIN_USAGE_GET`（30 次/分）。
- 快取：`usage-vercel`／`usage-firebase` 各自 5 分鐘記憶體快取（失敗結果只快取 30 秒），
  外部 API 每次實際呼叫至多 2 個。

## 資料來源與環境變數

| 來源 | 方式 | 環境變數 |
|---|---|---|
| Vercel | `GET https://api.vercel.com/v1/billing/charges?from&to[&teamId]`，Bearer token；逐行解析 JSONL，取 `ChargeCategory = Usage` 的 `ConsumedQuantity` 依 `ServiceName` 聚合（正規化比對 `SPECS.aliases`，未匹配者照實列出且無額度） | `VERCEL_TOKEN`、`VERCEL_TEAM_ID`（個人專案可不設）、`VERCEL_PLAN` |
| Firebase | Cloud Monitoring `projects.timeSeries.list`：`firestore.googleapis.com/document/{read,write,delete}_count`，`alignmentPeriod=3600`＋`ALIGN_SUM`＋`crossSeriesReducer=SUM`，程式依太平洋時間切日 | `FIREBASE_SERVICE_ACCOUNT_KEY`（需 `roles/monitoring.viewer`，缺權限時頁面顯示 gcloud 授予指令） |

- 單位換算：`usage-vercel.ts` 的 `normalizeUnit()`／`convert()`（bytes 家族、hours、gbHours、count），
  家族不同回 `null` → `unit="raw"`、`limit=null`。
- 權杖：Cloud Monitoring 存取權杖以 `google-auth-library` 取得並在記憶體快取 45 分鐘。

## 頁面

`src/app/admin/stats/page.tsx`（client）

- 工具列：資料更新時間＋「重新整理」鈕。
- Vercel 區塊：每資源一張「已用／額度」進度條（≥80% 警示色、≥100% 危險色）。
- Firestore 區塊：今日讀／寫／刪三張進度條；未設定或失敗時改顯示 `NoticeBox`（含設定指引）。
- 趨勢區塊：近 7 日讀／寫群組長條圖，**純 SVG**（不引入圖表函式庫）。
