## 五、出問題時

### 網站壞了

1. 先回滾部署（Vercel／App Hosting 的上一版）
2. 必要時 `git revert <commit>` 後 push
3. 公告說明影響範圍與修復進度

### 簽章或市集壞了

1. 暫停上架（不要 merge 新模組）
2. 跑 `npm run validate` 找哪個模組／公鑰有問題
3. 修正後重新部署 Pages

### 私鑰或 token 外洩

1. 立刻撤銷該金鑰（`npm run keys:revoke`）
2. 換新金鑰並重新簽章官方模組
3. 更新主程式內建公鑰與 `MODULE_MARKET_TRUSTED_KEYS`
4. 重新部署並公告
