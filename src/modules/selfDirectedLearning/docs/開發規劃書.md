# 自主學習計畫（selfDirectedLearning）開發規劃書

1. 狀態：**草案**（配套 `README.md`、`module.json`；本文件記錄需求背景、身分權限定案與待辦）
2. 對應模組：`value: selfDirectedLearning`、宿主 `campus-toolkit`（C，開發中）

## 一、需求背景：108 課綱「自主學習計畫」定義

<details open>
<summary>課綱定義</summary>

1. 學校每週提供 1–3 節的彈性學習時間。
2. 學生自行訂定 1 學期 21 或 22 週以內的學習方案。
3. 學習方案可安排於學校彈性學習時間期間，或課餘時間完成。
4. 得邀請學校教師或相關領域人士擔任指導教師。
5. 於學校彈性學習時間期間實施自主學習時，實施地點須在學校規範內。

</details>

## 二、身分與權限（勾選入口）

「勾選入口」在 manifest 的表達方式：`module.json` 的 `provides` 對應身分設為 `true`
（該身分首頁顯示本模組入口卡片）；各身分入口的**預設勾選狀態**另由 `defaultRoleEnabled`
控制（主程式 0.522+，缺省＝顯示）。

| 身分 | provides（勾選入口） | 使用者 | 功能範圍（草案，待細化） |
|---|---|---|---|
| 學生 | `true` | 本人 | 選定主題與學群、填報學習方案（依學校設定的可填寫週次完成每次課程安排、決定場地、指導老師非必填）、送出送審、查看審查意見與進度、結案 |
| 家長 | `true` | 子女在學 | 檢視學生的自主學習計畫（內容與審查狀態） |
| 教職員 | `true` | 指定審核人員／兼導師／指導教師 | 受指定為審核人員者為學生計畫提供審查意見；兼導師者瀏覽全班的自主學習計畫；得擔任指導教師 |
| 管理員（管理端） | `true`（依管理端慣例，如不需請告知） | 管理員 | 設定開放撰寫時間、校內彈性學習時間節次與行程、開放場域、審核人員等，並提供說明；模組設定與權限指派 |

1. 學生、家長、教職員三身分為本次定案（有入口、勾選）；管理端一列是骨架預設的假設，待你確認。
2. 入口預設勾選狀態（`defaultRoleEnabled`，如家長預設不勾）尚未定案。

## 三、辦理流程

<details open>
<summary>辦理流程四階段</summary>

1. **管理人員（前置設定）**：設定開放撰寫計畫的時間，設定校內彈性學習時間的節次與行程，設定哪些是開放場域與是否開放學生自行輸入場地，設定審核人員等，並提供說明。
2. **學生（撰寫與送審）**：在期限內上線，選定主題、學群（教育部 18 學群下拉選單；可選「其他」自行填寫名稱或說明），填寫指導老師（非必填），依表格逐週完成每次的課程安排、決定場地等（學習安排為所見即所得編輯器，支援字型、字級、粗斜體底線、文字顏色與底色調色盤、靠左／置中／靠右對齊圖示、清單、縮排、引用與刪除線；表格的第一欄為週次／日期／節次（節次分行），第二欄合併學習安排與場地（場地位於輸入框上方、靠左對齊），自動列出每週彈性學習時間的日期與節次；彈性形式以開始／結束週次選擇可寫區間，只列出可寫週次並即時檢核下限，起迄顛倒時先跳出確認再自動調換；與學校活動衝堂的週次顯示活動名稱、不提供撰寫；課餘時間另行處理），送出後等待學校審核人員回饋審查意見。頁面以獨立卡片呈現實施說明、我的計畫與撰寫計畫；我的計畫分為文件匣（正式、審核中）、草稿匣（草稿、退回修改）與垃圾桶（假性刪除、可還原）。撰寫時畫面左側有兩個浮動圖示（快速儲存草稿、列印預覽），表單頂部與底部都有加大的儲存／送出按鈕；列印預覽可開新分頁以 A4 紙張樣式檢視目前編輯內容（含未儲存變更）並列印。
3. **教職員（審核與瀏覽）**：
   1. 受指定為審核人員者：為學生的計畫提供審查意見。
   2. 兼導師者：可瀏覽全班的自主學習計畫。
4. **家長（檢視）**：查看學生的自主學習計畫。

</details>

## 四、`module.json` 定案（v1）

<details open>
<summary>已定案欄位</summary>

1. `routes`（8 條，四身分各一頁一 API）：
   1. `/admin/self-directed-learning`（page）＋ `/api/admin/self-directed-learning`（api）——設定與總覽。
   2. `/student/self-directed-learning`（page）＋ `/api/student/self-directed-learning`（api）——填報與進度；
      `/student/self-directed-learning/print`（page）——目前草稿的列印預覽（由撰寫頁以 postMessage 傳入，不寫入資料庫）。
   3. `/staff/self-directed-learning`（page）＋ `/api/staff/self-directed-learning`（api）——審核提供意見＋導師瀏覽全班（同頁分區）。
   4. `/parent/self-directed-learning`（page）＋ `/api/parent/self-directed-learning`（api）——檢視。
2. 權限：`permission.mode = "new"` 單一單位；**`managerPermissions` v1 不加**——「設定審核人員」是業務資料（存模組設定檔，可依學群指定），`staff` API 用 `requireRole("staff")` ＋驗是否在審核人員名單；導師瀏覽全班驗班級導師對應。
3. `rateLimits` 4 桶（前綴 `SELF_DIRECTED_LEARNING_`）：`LIST` 120/分、`STUDENT` 20/分、`STAFF` 60/分、`ADMIN` 60/分。
4. `auditActions` 4 項（前綴 `self_directed_learning_`）：`settings_updated`、`plan_submitted`、`plan_reviewed`、`plan_archived`。
5. `dataCollections` 3 集合：
   1. `selfDirectedLearningSettings`（doc `global`）——單文件設定，API 首讀 lazy init。欄位（v1 已實作於 `types/self-directed-learning.ts`）：
       1. `enabled: boolean`：功能總開關（預設 true；false＝維護中——學生／教職員／家長只見「目前此功能關閉維護中」，寫入 API 一律 403，管理端不受影響）。
       2. `openAt`／`closeAt`：開放撰寫起訖（epoch ms，null＝未設定）。
        3. `weekMode: "full" | "flexible"`：週數填寫形式（預設 `full`＝全學期空白週數都須填寫；
           `flexible`＝全學期採彈性週數填寫，選此項才有下限週數進階欄位）。
            **不存全學期週數（`maxWeeks` 已移除）**——實際週數受假期與定期考試影響並不固定，
            全學期形式的週數由系統讀主程式「學校基本設定 → 學期起訖設定」的
            **上課日起訖（優先）**、學期起訖或學年度起訖自動推算（`getFullWeeks()`），
            不開放人工設定。週計算依台灣公家機關慣例：週日為每週第一日、週六為最後日，
            第一週或最後一週未滿七日仍以一週計（學校通常為 21 或 22 週）。
        4. `minWeeks`：彈性形式的下限週數（預設 6、建議至少 6 週；全學期形式不使用）。
            儲存時以實際可寫週數（扣除全校學校活動造成的衝堂）檢核，超過可寫週數會拒絕；
            學生端以開始／結束週次選擇區間，剩餘可寫週數不足下限的開始週次不會列出。
        5. `slots: { day: 1-7, periods: string[] }[]`：校內彈性學習節次行程（週幾＋節次名稱）。
            學生端「撰寫計畫」的逐週表格以它推算每一週的**日期與節次**：週次與 `getFullWeeks()`
            一致（週日～週六為一週），日期＝該週週日＋（day % 7）日；節次名稱再對應主程式
            課表作息的起訖時間（作息文件缺漏時用內建八節＋午休）。
            並以行事曆行程的「學校活動層級」比對衝堂（唯讀）：全校、或該年級／該班級涵蓋學生
            且時間與節次重疊時，該時段顯示活動名稱、不提供撰寫；該週所有時段皆衝堂時整週
            不提供撰寫，送審時也不列入必填（`blockedWeeks`）。
        6. `venues: string[]`：開放場域。
        7. `venueEditable: boolean`：是否開放學生自行輸入場地名稱（預設 true）。`venues` 是學生可選的
           固定場域清單；true 時學生可在清單外自行輸入，false 時場地欄改為下拉選單、只能從清單
           選擇，送審時伺服器會檢查場地必須在清單內（`venueEditable: false`＋`venueOptions`）。
           關閉自行輸入但清單為空時，管理端會顯示警示。
        8. `reviewers: { uid, name }[]`：審核人員（uid 供 staff 端鑑權比對；v1 手動輸入，v1.1 擬改帳號選擇器）。
        9. `instructions: string`：自主學習實施說明（給學生、家長的總說明；上限 4000 字）。
        10. `writingInstructions: string`：自主學習計畫撰寫說明（學生發起新計畫、編輯草稿時顯示；上限 4000 字）。
        11. `updatedAt`：最後異動（epoch ms）。
   2. `selfDirectedLearningPlans`——學生計畫（主題、學群、指導老師、逐週安排、場地、狀態、送審時間）。
      逐週安排的 `content` 存淨化後的富文本 HTML（可見純文字上限 600 字、HTML 上限 6000 字元），
      允許粗體、斜體、底線、刪除線、顏色、字級、字型、對齊、清單、縮排與引用；舊版純文字仍相容。
      逐週安排仍保留 `timing`（學校彈性學習時間／課餘時間）供既有資料相容；學生端表格已移除
      「時段」欄，課餘時間的安排另行處理。
      `deletedAt`（epoch ms；null＝不在垃圾桶）：學生可把草稿／退回修改假性刪除，垃圾桶可還原；
      審核中與已通過不可刪除，教職員與家長端不顯示垃圾桶計畫。學生端「我的計畫」以
      文件匣（正式、審核中）／草稿匣（草稿、退回修改）／垃圾桶三分頁呈現。
   3. `selfDirectedLearningReviews`——審查意見紀錄（計畫 id、審核者、意見、時間；分離集合保留多輪歷程）。
6. `hooks`：`["announcements", "calendar"]`——開放撰寫發公告、開放／截止日期寫行事曆；
   另唯讀行事曆行程的「學校活動層級」做逐週彈性學習時間衝堂比對（不寫入行事曆）。
7. `icon` 維持 `selfDirectedLearning`（`ModuleIcon` 無此鍵走 fallback，不可手改 `ICON_PATHS`）；`defaultRoleEnabled` 不設（三身分入口缺省即顯示）。

</details>
