# 自主學習計畫（selfDirectedLearning）開發規劃書

1. 狀態：**草案**（配套 `README.md`、`module.json`；本文件記錄需求背景、身分權限定案與待辦）
2. 對應模組：`value: selfDirectedLearning`、宿主 `campus-toolkit`（C，開發中）

## 一、需求背景：108 課綱「自主學習計畫」定義

<details open>
<summary>課綱定義</summary>

1. 學校每週提供 1–3 節的彈性學習時間。
2. 學生自行訂定 1 學期 21 或 22 週以內的學習方案。
3. 學習方案可安排於學校彈性學習時間期間，或課餘時間完成。
4. 得邀請學校教師或相關領域人士擔任指導教師。
5. 於學校彈性學習時間期間實施自主學習時，實施地點須在學校規範內。

</details>

## 二、身分與權限（勾選入口）

「勾選入口」在 manifest 的表達方式：`module.json` 的 `provides` 對應身分設為 `true`
（該身分首頁顯示本模組入口卡片）；各身分入口的**預設勾選狀態**另由 `defaultRoleEnabled`
控制（主程式 0.522+，缺省＝顯示）。

| 身分 | provides（勾選入口） | 使用者 | 功能範圍（草案，待細化） |
|---|---|---|---|
| 學生 | `true` | 本人 | 選定主題與學群、填報學習方案（依學校設定的可填寫週次完成每次課程安排、決定場地、指導老師非必填）、送出送審、查看審查意見與進度、結案 |
| 家長 | `true` | 子女在學 | 檢視學生的自主學習計畫（內容與審查狀態） |
| 教職員 | `true` | 指定審核人員／兼導師／指導教師 | 受指定為審核人員者為學生計畫提供審查意見；兼導師者瀏覽全班的自主學習計畫；得擔任指導教師 |
| 管理員（管理端） | `true`（依管理端慣例，如不需請告知） | 管理員 | 設定開放撰寫時間、校內彈性學習時間節次與行程、開放場域、審核人員等，並提供說明；模組設定與權限指派 |

1. 學生、家長、教職員三身分為本次定案（有入口、勾選）；管理端一列是骨架預設的假設，待你確認。
2. 入口預設勾選狀態（`defaultRoleEnabled`，如家長預設不勾）尚未定案。

## 三、辦理流程

<details open>
<summary>辦理流程四階段</summary>

1. **管理人員（前置設定）**：設定開放撰寫計畫的時間，設定校內彈性學習時間的節次與行程，設定哪些是開放場域，設定審核人員等，並提供說明。
2. **學生（撰寫與送審）**：在期限內上線，選定主題、學群，填寫指導老師（非必填），依照學校所設定的可填寫週次完成每次的課程安排、決定場地等，送出後等待學校審核人員回饋審查意見。
3. **教職員（審核與瀏覽）**：
   1. 受指定為審核人員者：為學生的計畫提供審查意見。
   2. 兼導師者：可瀏覽全班的自主學習計畫。
4. **家長（檢視）**：查看學生的自主學習計畫。

</details>

## 四、`module.json` 定案（v1）

<details open>
<summary>已定案欄位</summary>

1. `routes`（8 條，四身分各一頁一 API）：
   1. `/admin/self-directed-learning`（page）＋ `/api/admin/self-directed-learning`（api）——設定與總覽。
   2. `/student/self-directed-learning`（page）＋ `/api/student/self-directed-learning`（api）——填報與進度。
   3. `/staff/self-directed-learning`（page）＋ `/api/staff/self-directed-learning`（api）——審核提供意見＋導師瀏覽全班（同頁分區）。
   4. `/parent/self-directed-learning`（page）＋ `/api/parent/self-directed-learning`（api）——檢視。
2. 權限：`permission.mode = "new"` 單一單位；**`managerPermissions` v1 不加**——「設定審核人員」是業務資料（存模組設定檔，可依學群指定），`staff` API 用 `requireRole("staff")` ＋驗是否在審核人員名單；導師瀏覽全班驗班級導師對應。
3. `rateLimits` 4 桶（前綴 `SELF_DIRECTED_LEARNING_`）：`LIST` 120/分、`STUDENT` 20/分、`STAFF` 60/分、`ADMIN` 60/分。
4. `auditActions` 4 項（前綴 `self_directed_learning_`）：`settings_updated`、`plan_submitted`、`plan_reviewed`、`plan_archived`。
5. `dataCollections` 3 集合：
   1. `selfDirectedLearningSettings`（doc `global`）——單文件設定，API 首讀 lazy init。欄位（v1 已實作於 `types/self-directed-learning.ts`）：
      1. `openAt`／`closeAt`：開放撰寫起訖（epoch ms，null＝未設定）。
      2. `maxWeeks`：方案可填週數上限（課綱 21/22 週，預設 22）。
      3. `slots: { day: 1-7, periods: string[] }[]`：校內彈性學習節次行程（週幾＋節次文字）。
      4. `venues: string[]`：開放場域。
      5. `reviewers: { uid, name }[]`：審核人員（uid 供 staff 端鑑權比對；v1 手動輸入，v1.1 擬改帳號選擇器）。
      6. `instructions: string`：給學生的說明（上限 4000 字）。
      7. `updatedAt`：最後異動（epoch ms）。
   2. `selfDirectedLearningPlans`——學生計畫（主題、學群、指導老師、逐週安排、場地、狀態、送審時間）。
   3. `selfDirectedLearningReviews`——審查意見紀錄（計畫 id、審核者、意見、時間；分離集合保留多輪歷程）。
6. `hooks`：`["announcements", "calendar"]`——開放撰寫發公告、開放／截止日期寫行事曆。
7. `icon` 維持 `selfDirectedLearning`（`ModuleIcon` 無此鍵走 fallback，不可手改 `ICON_PATHS`）；`defaultRoleEnabled` 不設（三身分入口缺省即顯示）。

</details>
