# 自主學習計畫（selfDirectedLearning）

選用功能模組（外掛），掛載於 `campus-toolkit` 主程式。依 108 課綱：學校每週提供 1–3 節
彈性學習時間，學生自行訂定 1 學期 21 或 22 週以內的學習方案，可安排於彈性學習時間或
課餘時間完成，得邀請學校教師或相關領域人士擔任指導教師；於彈性學習時間實施時，
地點須在學校規範內。

1. 開發者：[takan003](https://github.com/takan003)（`https://github.com/takan003/selfDirectedLearning`）
2. 版本：0.0.77（`contractVersion` 1、`minHostVersion` 0.580）
3. 四身分入口：管理員（設定與總覽）、學生（填報送審）、教職員（審核／兼導師瀏覽全班）、家長（檢視）

## 功能摘要

1. **管理端**（`/admin/self-directed-learning`）：「管理規則」頁設定功能總開關（關閉即全站
   維護中）、開放撰寫起訖、審核起訖（審核頁顯示期限、剩餘天數與逾期提醒，僅供督促、逾期仍可審核）、週數填寫形式（全學期全填／彈性下限）、下限週數、
   校內彈性學習節次行程（橫排上課日、直排節次的格狀勾選，取自學校課表作息）、開放場域（樓層空間建議＋可自訂；
   另可設定是否開放學生自行輸入場地）、
   審核人員名單、自主學習實施說明（給學生、家長的總說明）與自主學習計畫撰寫說明（發起新計畫、編輯草稿時顯示）。
   兩份說明都使用所見即所得編輯器（字型、字級、粗斜體底線、顏色與底色、對齊、清單、縮排、引用、清除格式），
   內容先經白名單 HTML 淨化後儲存；舊版純文字說明仍相容（自動保留換行）。
   全學期形式的週數**不人工設定**，由系統依「學校基本設定 → 學期起訖設定」的
   **上課日起訖（優先）**或學期起訖自動判斷（週日～週六為一週，未滿七日仍計一週）。
   彈性下限週數會以實際可寫週數檢核（扣除全校學校活動造成的衝堂）；
   超過可寫週數時管理端顯示警示並停用儲存，伺服器端也會拒絕。
   另可設定「計畫成果撰寫截止時間」（可設定到時與分）：學生填寫執行成果紀錄與學習反思心得
   只開放到此時間；未設定＝不限制填寫期限。
2. **學生端**（`/student/self-directed-learning`）：版面為數個獨立卡片（主色頂線、明顯框線與區塊標題）：
   自主學習實施說明（預設展開，可收合）、我的計畫、撰寫計畫（發出新計畫或編輯草稿時顯示）。
   「我的計畫」分為文件匣（正式、審核中）、草稿匣（草稿、退回修改）與垃圾桶（假性刪除）三個分頁，
   附圖示與數量；草稿與退回修改可移至垃圾桶，垃圾桶可還原（僅本人可操作；審核中與已通過不可刪除），
   開放狀態以醒目提示條顯示「開放撰寫中」與完整開放期間（截止時改用警示色），
   並顯示管理端設定的審核期間。
   開放撰寫期間且本學期尚無正式計畫時可發起新計畫；同一學期可有多筆草稿，
   但同時僅能有一件在審核中，正式計畫僅一份（送出審核一律歸為本學期，舊學期草稿送出時改記為目前學期）。
   審核中的計畫在開放撰寫期間內可「抽回修改」（警告色按鈕＋確認視窗）：抽回後回到草稿匣，
   審核人員即看不到該計畫，學生可修改後重新送出；限本學期、限開放期間，伺服器同步檢核。
   點「發起新計畫」或草稿的「編輯」才展開「撰寫計畫」表單：表單內顯示自主學習計畫撰寫說明，
   選主題與學群（教育部 18 學群下拉選單；可選「其他」自行填寫學群名稱或說明）、
   填指導老師（非必填）、
   填寫學習目標（送出審核時必填；所見即所得多行輸入，說明為「簡單扼要描述，建議採用條列陳述」，
   可見文字上限 600 字；草稿可先留白）、
   依週數形式完成逐週課程安排（全學期形式須填滿自動判斷的週數；彈性形式選擇開始／結束週次，
    只列出可寫週次並即時計算可寫週數，未達下限的區間會擋下送出；起迄顛倒時先確認再自動調換，
    場地＋學習安排）、開放期間內送出審核、查看審查意見（含審核人員填寫的逐週意見）。
    場地從學校開放場域下拉選擇；管理端開放自行輸入時，可選「其他」填寫自訂場地名稱。    學習安排使用零依賴所見即所得編輯器（字型、字級、粗斜體底線、文字顏色與底色調色盤、
    靠左／置中／靠右對齊圖示、清單、縮排、引用、刪除線、清除格式），內容先經白名單 HTML 淨化後儲存；可見純文字上限 600 字。
    逐週安排以表格呈現（第一欄為週次／日期／節次，節次分行；第二欄合併學習安排與場地，
    場地位於學習安排輸入框上方、水平靠左對齊），
    每週第一欄底部（下面還有一週時）有向下箭頭，可將本週學習安排與場地完整複製到下一週，
    自動推算該週彈性學習時間的**日期與節次**（依學期起訖與管理端勾選的節次行程）；
    該時段與行事曆的學校活動（全校／年級／班級）衝堂時，仍列出日期與節次，但該週顯示
    活動名稱、不提供撰寫，且不列入送審必填。課餘時間的學習安排另行處理（表格不再提供
    「時段」欄，既有資料的時段值保留）。
    草稿可分次儲存（未填完不擋），送出審核時才要求週數形式與每一週的學習安排／場地皆填妥。
    撰寫表單頂部與底部都有加大的「儲存草稿／送出審核」按鈕，長表單不必捲到底。
    撰寫時畫面左側有兩個跟隨捲動的浮動圖示：快速儲存草稿與列印預覽；
    點列印預覽可在新分頁以 A4 紙張樣式檢視目前編輯內容（含尚未儲存的變更）並列印；
    列印表頭包含學習目標（富文本），逐週表格與頁首頁尾維持原樣；
    列印輸出只保留紙張內容，按鈕、浮動圖示與陰影（含瀏覽器擴充套件注入的浮動面板）都不會被帶進 PDF。
   週數上限為程式判斷的總週數；扣除國定假日與學校重要行程後，依實際週數為總週數。
   「查看計畫與撰寫成果」與教職員審核頁一致：先顯示學習目標，逐週安排以表格呈現（表頭週次／學習安排／場地
   水平置中；週次欄垂直置中並列出週次、時段、日期、節次），逐週審查意見接在該週列下方。
   計畫通過審核後，「查看計畫與撰寫成果」的每一週列下方會多一塊「執行成果紀錄」（可單週收合／展開，
   預設收合；左側另提供浮動 SVG 按鈕可一次展開或收合全部，以及儲存成果）：每一週要等該週規劃時間
   （最後一個節次結束）過了才開放填寫，可由學生補寫先前週次；最後一週時間過了之後再開放
   「學習反思心得」。兩者都只開放到管理端設定的「計畫成果撰寫截止時間」（可設定到時與分），
   並以「儲存執行成果紀錄」按鈕一次儲存（所見即所得，可見文字上限 2000 字）。
   同一區塊上下都有「預覽列印（計畫與成果）」：按鈕旁可勾選成果紀錄呈現方式「分開式」（預設，另列於表格下方）
   或「融入式」（以跨「學習安排／場地」兩欄的獨立列併入當週）；以 A4 紙張樣式列印已通過的計畫內容、
   逐週執行成果紀錄與學習反思心得，週次欄比照計畫表列出時段、日期與節次（沿用撰寫表單的列印預覽頁，於新分頁開啟）。
3. **教職員端**（`/staff/self-directed-learning`）：受指定審核人員通過／退回（退回必填意見）；
   兼導師者瀏覽全班計畫。審核頁顯示管理端設定的審核期限、目前待審件數、剩餘天數與逾期提醒，
   每筆待審計畫顯示已等待天數以督促於期限內完成（期限僅供提示，逾期仍可審核）。
   審核佇列與全班清單採收合式摘要卡片（標題依「班號 姓名」顯示，另列主題／狀態／送出時間；
   展開後先顯示學習目標，逐週安排以表格呈現，每列為週次／學習安排／場地，
   週次欄另列該週的日期與節次（各一行），
   並在每週下方提供該週審查意見），
   並提供每頁 10／20／50／100 筆分頁（純前端切片，不增加讀取）。
   逐週意見與整體意見都使用所見即所得編輯器，並各自提供 5 種常用罐頭語可快速帶入；
   退回時整體意見必填，逐週意見可留空。
   配合主程式「省流開關」：啟用時先以 count 聚合取得待審件數並顯示「顯示審核列表」按鈕，
   按下後才載入計畫內容，避免一進頁面就讀取整批待審計畫。
4. **家長端**（`/parent/self-directed-learning`）：唯讀檢視自主學習實施說明、綁定子女的計畫
   （含學習目標）、逐週安排、逐週審查意見與審查狀態。
5. **總開關維護模式**：管理端關閉總開關後，學生／教職員／家長頁面一律只顯示
   「目前此功能關閉維護中」，寫入 API 回 403；管理端不受影響，可隨時改回開啟。
6. 狀態機：草稿 → 審核中 → 已通過（鎖定）／退回修改（可改再送）；審核中可在開放撰寫期間內
   抽回修改（回到草稿）；草稿與退回修改可移至垃圾桶（假性刪除、可還原；審核中與已通過不可刪除）。

## 資料集合清單（`dataCollections`，宣告即承諾）

1. `selfDirectedLearningSettings`（doc `global`）：模組設定單文件——`enabled`（功能總開關）、
   `openAt`／`closeAt`（開放起訖 epoch ms）、`reviewStartAt`／`reviewEndAt`（審核起訖 epoch ms；
   null＝未設定，僅供審核頁提示與督促）、`weekMode`（`full` 全學期全填／`flexible` 彈性
   下限）、`minWeeks`（彈性下限週數）、`slots`（節次行程）、`venues`（開放場域）、
   `venueEditable`（是否開放學生自行輸入場地名稱；false＝只能從 `venues` 清單選擇，送審會檢查）、
   `reviewers`（審核人員 uid＋名稱）、`instructions`（自主學習實施說明；淨化後 HTML）、
   `writingInstructions`（自主學習計畫撰寫說明；淨化後 HTML）、`updatedAt`。
   **不存全學期週數（`maxWeeks` 已移除）**：全學期形式的週數由主程式上課日／學期起訖自動推算
   （週日～週六為一週，台灣學校通常為 21 或 22 週）。
2. `selfDirectedLearningPlans`：學生計畫（doc id＝`{學年學期}_{uid}_{時間亂數}`；舊資料
   `{學年學期}_{uid}` 仍相容）——主題、學群、指導老師、學習目標（`learningGoals`，淨化後 HTML；
   送出審核時必填）、逐週安排（`weeks[]`：週次／內容／
   場地／時段；`content` 為淨化後的 HTML，舊版純文字仍相容）、`executionRecords[]`
   （逐週執行成果紀錄：`week`／`note`，淨化後 HTML）、`reflection`（學習反思心得，淨化後 HTML）、
   身分欄（班級等）、`status`、
   `deletedAt`（移至垃圾桶的時間；null＝不在垃圾桶）、`submittedAt`、`updatedAt`。同一學生同一學期
    可有多筆草稿，但同時僅能有一件在審核中（`submitted`），正式計畫（`approved`）僅一份；
    送出審核一律歸為**本學期**（舊學期草稿送出時寫入目前學期），送審與審核通過時都會檢查。
3. `selfDirectedLearningReviews`：審查意見（計畫 id、審核者、`decision`、整體 `note`、
   逐週 `weekNotes[]`（`week`／`note`，皆為淨化後 HTML）、`reviewedAt`；保留多輪歷程）。
4. `selfDirectedLearningLocks`：「學生＋學期」鎖定文件（doc id＝`{學年學期}_{uid}`）——
   `submittedPlanId`（目前審核中的計畫）、`approvedPlanId`（已通過的正式計畫）、`updatedAt`。
   送出審核、抽回、通過／退回都在 transaction 內讀寫同一份文件，讓同一學生同一學期的狀態轉換
   序列化，杜絕同時送審／同時通過的競態；沒有鎖定文件的舊資料仍以計畫清單掃描把關。

## 掛勾需求（`hooks`）

1. `announcements`（公告）：管理端**儲存設定**時以 `publishFromModule`／`updateFromModule`
   同步一則「自主學習計畫開放撰寫」公告（固定 `sourceRef: "open-window"`，重複儲存只更新不
   重複發文；清空開放時間即 `archived` 撤回）。
2. `calendar`（行事曆）：同步一筆行程（`publishScheduleFromModule` 同 `sourceRef` 覆寫更新；
   清空開放時間即 `cancelled`）。另**唯讀**行事曆行程的「學校活動層級」，比對逐週彈性學習時間
   是否衝堂（只比對涵蓋該學生年級／班級或全校的活動，不寫入行事曆）。
3. 兩者皆失敗**不阻擋**設定儲存——API 回 `hookWarning`，頁面以 Toast 提示。

## 安裝後設定方式

1. 安裝模組後至「功能模組管理」（`/admin/modules`）**啟用**本模組（預設未啟用，fail-safe 朝關）。
2. 為管理端指派本模組權限單位（`selfDirectedLearning`，權限類別「校務資料」）。
3. 開啟「管理規則」（`/admin/self-directed-learning`）：設定功能總開關、開放起訖、審核起訖、週數填寫
   形式與全學期／下限週數、節次行程、場域、審核人員與說明並儲存（儲存即同步公告與行事曆）。
4. 學生端需在開放期間內填報；教職員審核資格來自第 3 步的審核人員名單（管理員恆可審）。
   總開關關閉期間，非管理端一律只見「目前此功能關閉維護中」，資料不受影響。

## 開發環境

1. 本機路徑：`D:\workspace\CT\selfDirectedLearning`（宿主 `campus-toolkit` 同區並列）。
2. 掛載（宿主目錄執行，掛載前先停 dev server）：

   ```bash
   npm run module:link -- D:\workspace\CT\selfDirectedLearning --copy --watch
   ```

3. 驗 `module.lock.json` 的 `"source"` 為 `link-copy:`；驗收基準＝API 未登入回 401 而非 Build Error。
